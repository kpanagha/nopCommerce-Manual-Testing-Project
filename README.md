# nopCommerce Manual Testing Project

## Project Overview
This repository contains a Manual Testing project for the nopCommerce e-commerce application. The project demonstrates the software testing life cycle by preparing test cases, executing them, reporting defects, and generating test reports.

## Objectives
- Validate the functionality of the nopCommerce application.
- Identify and report defects.
- Prepare testing documentation following industry standards.
- Demonstrate manual testing skills through a real-time project.
